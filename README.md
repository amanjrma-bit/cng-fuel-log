# CNG Fuel Log

Phone app for CNG station pump attendants: log each bus (arrival, pump in/out, pump, kg, km, route), record pump meter readings, and send Excel reports on WhatsApp.

**Open it:** https://amanjrma-bit.github.io/cng-fuel-log/

- Works offline after the first open. Data stays on each phone.
- Android: open in Chrome, tap **Install app**.
- iPhone: open in Safari, tap **Share** → **Add to Home Screen**.
